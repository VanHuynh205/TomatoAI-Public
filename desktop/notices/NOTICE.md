# Thông báo thành phần Tomato Desktop

Bản Windows chạy DINOv2 v1 trên CPU. Mã ứng dụng do dự án viết dùng Apache License 2.0; bản MIT cũ giữ thông báo tại `project-MIT-legacy.txt`. Backbone DINOv2 của Meta AI giữ Apache 2.0. Nội dung chăm sóc giữ CC BY-SA 4.0. Giấy phép mã nguồn không cấp lại giấy phép cho dataset hoặc checkpoint tinh chỉnh. Chủ dự án yêu cầu đưa model vào GitHub Release để cộng tác; quyền dữ liệu vẫn còn các điểm chưa xác minh và chưa chốt giấy phép riêng cho checkpoint.

Thư mục notices/python giữ giấy phép và metadata của các gói Python đã khóa. Thư mục notices/cpython giữ giấy phép CPython. Các mục frontend, dinov2 và microsoft-webview2-sdk giữ thông báo của các thành phần tương ứng.
